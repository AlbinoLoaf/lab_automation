# lab_automation

This is our lab automation project for the course **Advanced Topics in Robiotics** (fall 2026) at the IT University of Copenhagen.

## Overview

The goal of this project is to develop a system for automatically mixing liquids and measuring the resulting color using a spectral sensor.

The robot uses pumps to push liquids into a tube. A spectral sensor behind the tube measures the light spectrum passing through the liquid.
